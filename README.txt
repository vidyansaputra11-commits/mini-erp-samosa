MINI ERP PRODUKSI - ANDROID / PWA

Fitur:
- Order Reguler & Reseller dengan harga berbeda
- Rekap order dan print struk
- Pembelian & pemakaian Raw Material
- Pembelian & pemakaian Packaging INNER/OUTER
- Input hasil produksi & reject
- Stok RM, Packaging, Finish Good
- Outstanding produksi otomatis dari order aktif vs stok FG
- Laporan penjualan, HPP, profit kotor
- Print laporan
- Backup/restore data JSON
- Offline-first

CATATAN INSTALASI
Versi ini adalah Progressive Web App (PWA). Agar tombol "Install app / Tambahkan ke layar utama" Android aktif, folder harus disajikan melalui HTTPS (misalnya GitHub Pages / hosting web).

APK native belum disertakan karena environment pembuatan saat ini tidak memiliki Android SDK/Gradle. Seluruh source siap dipaketkan menjadi APK melalui Android Studio/Capacitor pada tahap berikutnya.
